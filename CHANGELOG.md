# Changelog

## 1.5.0

- Add an optional “Organize uploads by page” setting for new Dropbox uploads, including paste, drag-and-drop, and the file picker. The setting is off by default.
- Create and reuse folders named for the destination Roam page, with unique filenames for repeated uploads. Existing files stay in place; page renames affect future uploads only.
- Use direct file links for uploads inside shared folders, and show folder errors without silently uploading to the root.
